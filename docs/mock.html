Context Commands

Retrieves user info, company, auth token, and other session data.

Get Activity

Save Activity

Omit "id" to create new, include "id" to update existing.

Get Company Info

Retrieves all company configuration data including name, address, currency settings, bank details, and other company-level settings. Typically there is only one CompanyInfo instance. This is a read-only operation.

Get Time Effort by ID

Retrieves a single Time Effort by its ID.

Get Time Efforts by Parent Object

Retrieves all Time Efforts associated with a parent object (e.g., Activity, ServiceCall). Requires both objectId and objectType. Returns an array of Time Efforts.

Save Time Effort

Omit "id" to create new, include "id" to update existing. Time Efforts track work time, breaks, and are associated with tasks and objects.

Get Equipment

Retrieves an Equipment by its ID. Equipment represents physical assets like machines, tools, or devices.

Save Equipment

Omit "id" to create new, include "id" to update existing. Required fields: name, serialNumber.

Get Person

Retrieves a Person by its ID. Person is read-only — there is no Save Person command.

Get Logged-In Person

Retrieves the currently logged-in user's Person. No ID required.

Get Service Call

Retrieves a Service Call by its ID. "Get Activities" returns the IDs of all Activities linked to this Service Call. Service Call is read-only — there is no Save Service Call command.

Add Attachment (Upload File)

Selected file:

Select a file from your device to upload as an attachment. The file will be converted to base64 and sent to the native app.

List Attachments by Parent Object

Retrieves all attachments associated with a parent object. Returns an array of attachment metadata (without file content).

Get Attachment

If content is not cached locally, it will be downloaded from cloud. Default: 30000ms (30s)

If includeContent=true and the file is not cached locally, the app will attempt to download it from cloud within the timeout period.

Download Attachment (to Device)

Download an attachment to a user-selected location on the device. Supports two modes:

📥 Mode 1: Download by Attachment ID
Default: 60000ms (60s). Increase for large files not yet cached.
— OR —
📥 Mode 2: Download Binary Content

The native file picker will open for the user to select the save location. Mode 2 is useful for dynamically generated files or split file assemblies.

Remove Attachment

Warning: This will permanently delete the attachment!

Get UDO Meta by ID

Retrieves the schema/metadata definition for a User Defined Object type by its ID, including name, description, and field definitions (UdfMetas).

Get UDO Meta by Name

Retrieves the schema/metadata definition for a User Defined Object type by its name. Useful when you know the UDO type name but not the internal GUID.

Get UDF Meta by ID

Retrieves the field metadata definition for a User Defined Field by its ID. UDF Meta defines field name, type, validation rules, etc.

Get UDF Metas by UDO Name

Retrieves all UDF (User Defined Field) metadata definitions associated with a UDO by the UDO's name. Returns an array of UDF Metas.

Get UDF Metas by Object Type

Retrieves all UDF (User Defined Field) metadata for a specific object type (e.g., all custom fields defined for Activities). Returns the complete list of UDF definitions, not just filled-out ones. Matching is case-insensitive.

Get UDO Value

Retrieves a User Defined Object value instance by its ID.

Save UDO Value

Omit "id" to create new, include "id" to update existing. UDO Values are instances of User Defined Objects configured via UdoMeta.

Remove UDO Value

Warning: This will delete the UDO Value! If already synced to the server, it will be marked as deleted. If never synced, it will be permanently removed.

Query UDO Values

Query UDO Values by UdoMeta (required), optionally filtered by a specific UDF field and value.

Workflow:
1. Use "UDO" tab → "Get UDO Meta by Name" to find the UdoMeta ID
2. Use "UDO" tab → "Get UDF Metas by UDO Name" to find UDF field IDs
3. Enter the IDs below and query
📘 UDO Meta (Required - use ONE)
— OR —
📗 UDF Filter (Optional - use ONE if filtering)
— OR —
📙 UDF Value (Required if UDF Meta is specified above)

Returns all UDO Values matching the criteria. If UDF filter is specified, only UDO Values containing that field with the matching value are returned.

UI & Message Commands

Commands for displaying native UI elements like toasts and notifications.

🔔 Show Toast Notification

Displays a native Android toast notification at the bottom of the screen. The PWA selects a predefined key; the host resolves the localized message. Toasts are non-blocking and automatically disappear after a few seconds (LENGTH_LONG ~3.5s).
